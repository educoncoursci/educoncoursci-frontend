⏰ Rappels automatiques

Ces rappels partent désormais automatiquement tous les jours à 8h pour les concours dont la clôture approche (J-7, J-3, J-1), en respectant les préférences de chaque utilisateur (email/WhatsApp, catégories). Le bouton ci-dessous reste utile pour un envoi immédiat ponctuel (les doublons sont automatiquement évités).

File d'attente WhatsApp

Tant qu'aucune API WhatsApp Business officielle n'est configurée (voir .env), les messages atterrissent ici pour un envoi manuel via WhatsApp Web/Business. Marque-les comme envoyés une fois fait.
