🔑 Variables d'environnement Railway

Ces variables doivent être configurées dans ton projet Railway → Settings → Variables.

PORT
Port du serveur Express
Exemple : 3000
Requis
NODE_ENV
Environnement (production/development)
Exemple : production
Requis
FRONTEND_URL
URL du frontend Netlify
Exemple : https://educoncoursci.netlify.app
Requis
DATABASE_URL
URL complète PostgreSQL (auto-générée par Railway)
Exemple : postgresql://...
Requis
JWT_SECRET
Clé de signature des tokens JWT
Exemple : une_clé_secrète_longue
Requis
JWT_EXPIRES_IN
Durée de validité des tokens
Exemple : 7d
Requis
ANTHROPIC_API_KEY
Clé API Claude (console.anthropic.com)
Exemple : sk-ant-...
Requis
WAVE_NUMERO
Numéro Wave CI marchand
Exemple : 07XXXXXXXX
Requis
OM_NUMERO
Numéro Orange Money marchand
Exemple : 07XXXXXXXX
Requis
EMAIL_HOST
Serveur SMTP pour les e-mails
Exemple : smtp.gmail.com
Requis
EMAIL_PORT
Port SMTP (587 pour TLS)
Exemple : 587
Requis
EMAIL_USER
Adresse Gmail pour l'envoi
Exemple : ton@gmail.com
Requis
EMAIL_PASS
Mot de passe application Gmail
Exemple : mot_de_passe_app
Requis
EMAIL_FROM
Expéditeur affiché
Exemple : EduConcoursCI <noreply@educoncoursci.ci>
Requis
ADMIN_EMAIL
E-mail du compte admin par défaut
Exemple : ton@email.com
Requis
ADMIN_PASSWORD
Mot de passe admin initial (change-le après connexion)
Exemple : MotDePasseAdmin123!
Requis
MAX_FILE_SIZE_MB
Taille max upload PDF en MB
Exemple : 10
◎ Optionnel
UPLOAD_PATH
Dossier de stockage des PDFs uploadés
Exemple : ./uploads
◎ Optionnel
