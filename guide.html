Comment payer

Via Wave CI
  1. Ouvrez l'app Wave
  2. Envoyez le montant exact au numéro marchand
  3. Notez l'ID de transaction (ex: WA-AB12345)
  4. Saisissez l'ID sur la page paiement
🟠 Via Orange Money
  1. Compose #150*1*1*NUMERO*MONTANT#
  2. Confirmez avec votre PIN
  3. Notez l'ID dans le SMS reçu
  4. Saisissez l'ID sur la page paiement

Questions fréquentes

La plateforme est-elle gratuite ?
Oui, l'inscription et l'accès de base sont entièrement gratuits. Les informations sur les concours sont toujours gratuites. Le Premium (payant) concerne uniquement les services d'insertion professionnelle (CV, lettres, analyse et adaptation aux offres).
Mes données sont-elles sécurisées ?
Oui. Les mots de passe sont hashés (bcrypt) et les tokens JWT expirent automatiquement. Aucune donnée bancaire n'est stockée.
Puis-je utiliser la plateforme hors ligne ?
Partiellement. Le site peut être installé comme application PWA (ajoute-le à l'écran d'accueil). Les pages déjà visitées restent accessibles sans connexion.
Comment contacter le support ?
Par e-mail à support@proinsertionci.ci. Nous répondons en moins de 48h.
Les concours sont-ils mis à jour en temps réel ?
Oui, notre équipe met à jour les fiches concours dès les annonces officielles.
